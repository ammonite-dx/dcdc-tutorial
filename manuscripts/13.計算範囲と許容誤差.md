# 第13章　計算範囲と許容誤差

前章では、数学上の確率分布と、計算機上で明示的に保持する有限な配列表現を区別した。

台（support）が有限であれば、その全体を配列へ完全に保存できる。しかし、クリティカルを伴う判定のように台が無限に続く場合、すべての確率を有限の配列へ格納することはできない。

そこで必要になるのが、次の工学的な判断である。

> **どこまでを明示的に計算すれば、残りを無視できるほど十分に小さいと言えるのか。**

単に「このあたりから確率が小さそうだから適当に打ち切る」という曖昧な運用では、計算結果の信頼性を保証できない。

本章では、明示範囲の外側に残される微小な確率を**裾確率**（tail確率）として厳密に評価し、「明示しなかった確率は高々 $\varepsilon$ 以下である」という数学的保証のもとで計算範囲（cutoff）を逆算する手法を導出する。さらに、確率のtailが小さいことと、期待値への影響が小さいことは同義ではないという重要な事実にも光を当てる。

## 13.1 明示範囲の外側を裾確率（tail確率）で表す

整数値をとる確率変数 $X$ を考える。ある境界値 $w$ より大きい結果が出る確率を、

$$
\boxed{
T_X(w) = P(X > w)
}
$$

と定義し、これを $X$ の**上側裾確率**（upper tail probability; tail確率）と呼ぶ。累積分布関数 $F_X(w) = P(X \le w)$ との間には、余事象の定義から次の関係が成り立つ。

$$
\boxed{
T_X(w) = 1 - F_X(w)
}
$$

第12章で見たように、配列の最大インデックスを値 $w$ に対応させたとき、配列の外側に溢れ出る未表現の確率質量は、まさにこの $T_X(w)$ そのものである。

台が有限な分布において、$w$ を台の最大値以上に設定すれば $T_X(w) = 0$ となり、裾確率は完全に消滅する。一方、無限の台を持つ分布では、いかに大きな有限値 $w$ を選んだとしても、一般に $T_X(w) > 0$ である。

## 13.2 「十分小さいから無視する」を数式にする（許容誤差）

計算範囲を値 $w$ までとし、その裾確率がある小さな正の実数 $\varepsilon > 0$ 以下に抑えられていることが分かったとしよう。

$$
T_X(w) \le \varepsilon
$$

これは、「**計算していない範囲に入る確率は、最大でも $\varepsilon$ である**」という厳密な数学的保証（契約）を意味する。たとえば $\varepsilon = 10^{-8}$ と設定すれば、明示範囲の外側へ出る確率は1億分の1以下に抑えられている。

ここで強調すべきは、tailを「確率0とみなして無視した」のではなく、「**真の残差が区間 $[0, \varepsilon]$ に収まっていることが証明されている**」という点である。したがって、この有限範囲の配列を用いて計算された任意の事象の確率と、真の確率との誤差も、打ち切りに起因する分については高々 $\varepsilon$ 以下となる。

この目標値 $\varepsilon$ を、あらかじめ定めた**許容誤差**（tolerance）と呼ぶ。重要なのは思考の順序である。

> 計算してから「残りはたぶん小さいだろう」と推測するのではなく、**最初に保証すべき許容誤差 $\varepsilon$ を決定し、その条件を満たす最小の計算範囲 $w$ を逆算する**。

このアプローチによって初めて、計算機による確率計算は数学的な正当性を獲得する。

## 13.3 各種判定における tail の評価

それでは、ダブルクロスの主要な判定について、裾確率 $T(w)$ を具体的に評価してみよう。

### 1. 1DX$c$ の裾確率
第3章で求めた1DX$c$ の累積分布関数の閉形式 $F_c(x)$ を用いると、整数 $x = 10k + r$（$k\ge0, 0\le r\le 9$）に対する裾確率は次式となる。

$$
\boxed{
T_c(10k + r) = 1 - F_c(10k + r) = \frac{10 - \min(r, c-1)}{10} q_c^k
}
$$

ここで $q_c = (11-c)/10$ はクリティカル確率である。最も重要なのは、**裾確率がクリティカル回数 $k$ に対して等比級数（公比 $q_c$）の速度で指数関数的に激減する**という点である。

C7（$q_7 = 0.4$）であれば、$k$ が1増える（出目が10増える）ごとにtailは $0.4$ 倍（半分以下）になり、30回クリティカル（出目300程度）すれば $0.4^{30} \approx 1.15 \times 10^{-12}$ と、倍精度浮動小数点数の限界に迫る微小値となる。

### 2. 複数ダイス $n$DX$c$ の裾確率
第4章で示した通り、$n$DX$c$ の出目 $D_{n,c}$ の累積分布関数は $F_c(x)^n$ である。したがって、その裾確率は

$$
\boxed{
T_{n,c}(w) = 1 - F_c(w)^n
}
$$

となる。ここで $F_c(w) = 1 - T_c(w)$ であるから、二項展開または Bernoulli の不等式（$n T_c(w) \ll 1$ のときの近似）を用いると、

$$
T_{n,c}(w) = 1 - (1 - T_c(w))^n \approx n \cdot T_c(w)
$$

という極めて直感的な関係が成り立つ。すなわち、$n$ 個のダイスのいずれかが境界 $w$ を超える確率は、単一ダイスの裾確率の概ね $n$ 倍で抑えられる。

したがって、$n$DX$c$ において裾確率を $\varepsilon$ 以下に抑えるための条件は、およそ

$$
n \cdot T_c(w) \le \varepsilon \quad\Longleftrightarrow\quad T_c(w) \le \frac{\varepsilon}{n}
$$

を満たす最小の $w$ を選べばよいことになる。

### 3. 《支配の領域》の裾確率
第9章で扱った《支配の領域》（上位 $m$ 個のダイスを1に落とす効果）では、結果は順序統計量 $D_{n,m,c} = Z_{[m+1]}$（上から $m+1$ 番目に大きい出目）となった。

出目が境界 $w$ を超えるダイスの個数を $K_w$ とすると、$n$ 個のダイスは独立であるから、
$$
K_w \sim \operatorname{Bin}(n, T_c(w))
$$
という二項分布に従う。上から $m+1$ 番目の値が $w$ を超えるためには、少なくとも $m+1$ 個のダイスが同時に $w$ を超えていなければならない。したがって、その裾確率は

$$
\boxed{
P(D_{n,m,c} > w) = P(K_w \ge m + 1) = \sum_{j=m+1}^n \binom{n}{j} T_c(w)^j (1 - T_c(w))^{n-j}
}
$$

となる。大きな値が出るためには1個だけでなく $m+1$ 個のダイスが同時に大爆発しなければならないため、《支配の領域》適用後のtailは、通常の判定よりもはるかに高速に減衰する。

### 4. 《妖精の手》の裾確率
第8章で扱った《妖精の手》では、通常判定の最大クリティカル回数 $M$ に加え、負の二項分布に従う追加クリティカル回数 $S_y$ が畳み込まれる。

この場合も、総合クリティカル回数 $T = M + S_y$ の尾部は幾何分布と同等の指数的減衰を示すため、累積分布の解析的評価あるいは Chernoff バウンドによって、安全なカットオフ境界 $w$ を容易に導出できる。

## 13.4 許容誤差から計算範囲（cutoff）を逆算するアルゴリズム

許容誤差 $\varepsilon$（例：$10^{-8}$）を決めたとき、実際にプログラムが確保すべき最小の配列上限 $w$（cutoff）はどのように探索すればよいだろうか。

裾確率には、
$$
w_1 \le w_2 \implies T_X(w_1) \ge T_X(w_2)
$$
という厳密な単調減少性がある。したがって、すべての整数 $w = 0, 1, 2, \ldots$ を1つずつ愚直に試す必要はない。

DCDCなどの実装では、**指数探索（Exponential Search）と二分探索（Binary Search）**を組み合わせることで、極めて高速に必要なカットオフ $w$ を決定する。

```text
// 許容誤差 ε を満たす最小の cutoff w を逆算する
function findCutoff(epsilon):
    // ステップ1: 境界を倍々に広げて探索区間を絞り込む
    bound ← 16
    while T_X(bound) > epsilon:
        bound ← bound * 2

    // この時点で T_X(bound/2) > epsilon かつ T_X(bound) <= epsilon が確定
    low ← bound / 2
    high ← bound

    // ステップ2: 区間 [low, high] で二分探索
    while low < high:
        mid ← floor((low + high) / 2)
        if T_X(mid) <= epsilon:
            high ← mid
        else:
            low ← mid + 1

    return low
```

このアルゴリズムの極めて重要な点は、**「巨大な確率分布配列を実際にメモリ上に確保する前に、tailの閉形式だけを評価して必要な計算範囲を先回りして決定している」**ことである。

計算範囲の**「計画（Planning）」**と、実際の分布の**「生成（Generation）」**を完全に分離することにより、無駄なメモリ再確保を未然に防ぎ、最小限のメモリ消費で精度保証を実現できる。


## 13.5 複数の確率分布へ許容誤差を配分する

ゲーム全体のシミュレーション（たとえば「命中判定 $\to$ ダメージダイス混合 $\to$ 装甲値減算」）を行う場合、複数のステップで確率分布の畳み込みや混合が発生する。

2つの独立な確率変数の和 $Z = X + Y$ を考える。$X$ の計算範囲を $w_X$（誤差 $\varepsilon_X$）、$Y$ の計算範囲を $w_Y$（誤差 $\varepsilon_Y$）で打ち切ったとき、和 $Z$ が範囲 $w_X + w_Y$ を超える確率はどうなるだろうか。

事象 $\{X + Y > w_X + w_Y\}$ が発生するためには、少なくとも $\{X > w_X\}$ または $\{Y > w_Y\}$ のいずれかが発生していなければならない。事象の和事象の確率に対する劣加法性（Union Bound）より、

$$
P(X + Y > w_X + w_Y) \le P(X > w_X) + P(Y > w_Y) \le \varepsilon_X + \varepsilon_Y
$$

が常に成り立つ。

つまり、**各ステップで許容した誤差の上限は、畳み込みによって単純に足し算される**。

したがって、最終的な計算結果全体で誤差を $\varepsilon_{\text{total}} = 10^{-6}$ 以下に抑えたいのであれば、計算パイプラインに含まれる各サブステップ（判定、ダメージ混合等）に対して、たとえばそれぞれ $\varepsilon_i = 10^{-7}$ のように誤差枠を分割して配分すればよい。

## 13.6 裾の一次モーメントと期待値の保証

ここで、離散確率論における極めて重要かつ見落とされやすい警告を発しておかなければならない。

> **「裾確率（tail確率）が小さい」ことと、「期待値への影響が小さい」ことは、全くの別問題である。**

期待値の定義は $E[X] = \sum_x x\, p_X(x)$ である。境界 $w$ より上の未計算部分が期待値に与える寄与（期待値のtail）は、次式で定義される。

$$
\boxed{
E_{\text{tail}}(w) = \sum_{x > w} x\, p_X(x)
}
$$

もし確率変数が巨大な値 $x$ を取る可能性を持っている場合、たとえ確率 $p_X(x)$ そのものは $10^{-8}$ のように極小であっても、$x$ 自身が $10^9$ のように巨大であれば、その積 $x \cdot p_X(x) = 10$ となり、期待値全体を大きく狂わせてしまう（いわゆるヘビーテイル問題）。

幸いにして、ダブルクロスのクリティカル判定において、確率質量は等比級数 $q_c^k$（指数的）に減少する。指数関数的な減衰は、いかなる多項式的な値の増大 $x = 10k$ よりも圧倒的に速く0へと収束する。

### 一次モーメントの安全なバウンド

具体的に 1DX$c$ の期待値tail $E_{\text{tail}}(10K)$ を評価しよう。等比数列の公式と級数の微分 $\sum_{k=K}^\infty k q^k = \frac{K q^K}{1-q} + \frac{q^{K+1}}{(1-q)^2}$ を用いると、期待値の誤差上界は次のように抑えられる。

$$
E_{\text{tail}}(10K) \le 10 \left( \frac{K q_c^K}{1 - q_c} + \frac{q_c^{K+1}}{(1 - q_c)^2} \right)
$$

$q_c = 0.4$ であれば、$K=20$（出目200まで計算）とするだけで、期待値への未計算分の影響は $10^{-6}$ 未満にまで激減する。

したがって、期待値の精度を保証したい場合は、単に $P(X > w) \le \varepsilon$ を満たすだけでなく、この**一次モーメントのtail上界** $E_{\text{tail}}(w) \le \delta$ も同時に満たすようにカットオフ境界 $w$ を決定しなければならない。

## 13.7 必要な精度を満たせない場合の保護（リソース制御）

計算機のリソース（メモリや実行時間）は有限である。

たとえば、極端なパラメータ（ダイス数が100万個、C値2など）が入力された場合、要求された許容誤差 $\varepsilon = 10^{-12}$ を満たすために必要な配列長 $L$ を計算すると、配列長が数億要素に達し、ブラウザのメモリが枯渇（OOMクラッシュ）してしまう恐れがある。

本物の堅牢な計算器を実装する上では、次のような**リソース防壁（Resource Admission Control）**を組み込むことが不可欠である。

```text
function determineWorkingLength(diceCount, criticalValue, tolerance, maxAllowedLength):
    w ← calculateRequiredCutoff(diceCount, criticalValue, tolerance)

    if w > maxAllowedLength:
        // メモリ上限を超える場合、無理に計算を実行してクラッシュさせない
        raise ResourceLimitExceededError("要求精度を満たす計算範囲がメモリ許容上限を超えています")

    return w
```

「計算を途中で破綻させるくらいなら、計算を開始する前に数学的に見積もり、安全に拒絶する」。この設計思想が、Webアプリケーションとしての安定性を担保する。

## 13.8 この章で使った道具

* **裾確率（tail確率）**:
  $$
  T_X(w) = P(X > w) = 1 - F_X(w)
  $$
* **1DX$c$ の裾確率**:
  $$
  T_c(10k + r) = \frac{10 - \min(r, c-1)}{10} q_c^k
  $$
* **複数ダイスの裾確率上界**:
  $$
  T_{n,c}(w) = 1 - F_c(w)^n \le n \cdot T_c(w)
  $$
* **独立和における誤差の劣加法性**:
  $$
  T_{X+Y}(w_X + w_Y) \le T_X(w_X) + T_Y(w_Y) \le \varepsilon_X + \varepsilon_Y
  $$
* **期待値のtail（一次モーメント）バウンド**:
  $$
  E_{\text{tail}}(w) = \sum_{x > w} x\, p_X(x)
  $$

## 第IV部のまとめ

第12章と第13章によって、数学上の確率モデルをコンピュータ上に正しく落とし込むための工学的基盤が完成した。

1. **第12章**: 配列の添字と値を切り離すオフセット記法を導入し、台が無限の分布に対しても「明示範囲」と「境界外のoverflow契約」を分離して安全に保持するデータ構造を設計した。
2. **第13章**: 幾何級数的なtail確率の減衰特性を利用し、あらかじめ定めた許容誤差 $\varepsilon$ から必要な配列長 $w$ を逆算する数学的基準を確立した。

ここまでの道具を用いれば、動的計画法（DP）と配列操作によって、任意のダブルクロスの確率分布を「正しく、誤差が保証された形」で計算できる計算器を実装できる。

しかし、大量のダイスを振るダメージロールや、多数の判定を高速に処理する必要があるWebサービスにおいては、素朴な畳み込み $O(N^2)$ の実行速度が次なるボトルネックとして立ちはだかる。

続く**第V部**では、多項式・確率母関数（PGF）という代数学の架け橋を渡り、**高速フーリエ変換（FFT）**と**周波数領域解析**による極限の超高速アルゴリズムの世界へと突入する。
