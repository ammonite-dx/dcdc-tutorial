# 第2章　独立な和と畳み込み

前章では、単一の確率変数について、その確率分布を確率質量関数（PMF）や累積分布関数（CDF）で表す方法を見た。しかし、実際のTRPGでは複数のランダムな値を組み合わせて使うことが多い。たとえば2D10の合計値を求めるには、2個の公平な10面ダイスの出目を足し算する必要がある。

本章では、互いに独立な二つの確率変数を足したとき、その和の確率分布をどのように求めるかを考える。この計算を追う過程で、離散確率計算の柱となる**畳み込み**（convolution）と**動的計画法**（dynamic programming; DP）という基本的かつ強力な道具を導入する。以降のダメージ計算や特殊なダイス処理でも、この二つの考え方は繰り返し登場する。

## 2.1 2個のD10を振って足す（2D10の合計）

2個の公平なD10を振る場合を考えよう。それぞれの出目を $X$、$Y$ とし、その合計を $S = X + Y$ とする。

このとき、合計 $S$ が7になる事象を考える。出目の組 $(X, Y)$ としてあり得るのは、

$$
(1, 6),\ (2, 5),\ (3, 4),\ (4, 3),\ (5, 2),\ (6, 1)
$$

の6通りである。2個のダイスは互いに干渉せず独立に振られるため、どの特定の組み合わせが出る確率も一律に $1/10 \times 1/10 = 1/100$ である。したがって、

$$
P(S = 7) = 6 \times \frac{1}{100} = \frac{6}{100} = 0.06
$$

となる。ここで、「一方の結果がもう一方の出目の確率に何ら影響を与えない」という性質を確率変数の**独立性**（independence）と呼ぶ。

同様にして取り得るすべての合計値 $s \in \{2, 3, \ldots, 20\}$ について計算すると、2D10の確率分布は次のようになる。

| 合計 $s$ | $(X, Y)$ の組み合わせ | 確率 $P(S=s)$ |
| :---: | :--- | :---: |
| 2 | $(1,1)$ | $1/100$ |
| 3 | $(1,2), (2,1)$ | $2/100$ |
| 4 | $(1,3), (2,2), (3,1)$ | $3/100$ |
| $\vdots$ | $\vdots$ | $\vdots$ |
| 10 | $(1,9), (2,8), (3,7), (4,6), (5,5), (6,4), (7,3), (8,2), (9,1)$ | $9/100$ |
| 11 | $(1,10), (2,9), (3,8), (4,7), (5,6), (6,5), (7,4), (8,3), (9,2), (10,1)$ | $10/100$ |
| 12 | $(2,10), (3,9), (4,8), (5,7), (6,6), (7,5), (8,4), (9,3), (10,2)$ | $9/100$ |
| $\vdots$ | $\vdots$ | $\vdots$ |
| 19 | $(9,10), (10,9)$ | $2/100$ |
| 20 | $(10,10)$ | $1/100$ |

1D10はどの出目も同じ確率 $1/10$（一様分布）であったが、2D10の合計は中央値付近の11が最も出やすく、端に行くほど出にくくなる「山型」の分布を描く。この違いは、出目そのものの重みではなく、その合計値を作り出す**組み合わせ（場合の数）の違い**によって生じている。

## 2.2 和の確率を系統的に求める（畳み込みの定義）

この計算を一般的な数式へと抽象化しよう。和 $S = X + Y$ がある値 $s$ になるためには、$X$ がある値 $x$ を取り、かつ $Y$ が残りの $s - x$ を取ればよい。

$X$ が取り得るすべての $x$ についてこの排反な事象を足し合わせれば、和の確率は次のように書ける。

$$
P(S = s) = \sum_x P(X = x, \ Y = s - x)
$$

$X$ と $Y$ が独立であれば、同時確率はそれぞれの確率の積 $P(X=x) P(Y=s-x)$ に分解できる。したがって、確率質量関数を用いれば、次の基本式が得られる。

$$
\boxed{
p_S(s) = \sum_x p_X(x) p_Y(s - x)
}
$$

この演算を二つの確率質量関数 $p_X$ と $p_Y$ の**畳み込み**（convolution）と呼び、数学的には演算子「$*$」を用いて

$$
p_S = p_X * p_Y
$$

と表記する。「合計が $s$ になるすべての組み合わせを探し、確率を掛けてから足し合わせる」という操作そのものを表している。

## 2.3 3個以上のダイスへ広げる（畳み込みの反復）

同様の手法を用いれば、3D10の分布も計算できる。3個のD10の出目を $X, Y, Z$ とし、合計を $S_3 = X + Y + Z$ としよう。

もしすべての出目の組 $(x, y, z)$ を愚直に列挙しようとすると、$10^3 = 1000$ 通りのパターンを網羅しなければならない。これが $n$ 個のダイスとなれば、候補の総数は $10^n$ 通りという天文学的な数に跳ね上がり、コンピュータを用いても計算不能に陥る（**組み合わせ爆発**）。

しかし、ここで和の結合法則に注目しよう。3個の和は「最初の2個の和」に「3個目のダイス」を足したものと等しい。

$$
S_3 = (X + Y) + Z = S_2 + Z
$$

すでに2D10の合計 $S_2$ の分布 $p_{S_2}$ は求まっている。したがって、三つの出目を最初から同時に列挙する必要はまったくなく、**「2D10の合計 $S_2$」と「新しい1個のD10の出目 $Z$」の畳み込み**を1回計算するだけでよい。

$$
p_{S_3} = p_{S_2} * p_Z
$$

### 過去の細かい経過を忘れる

この見方で最も本質的なのは、「**最初の2個のダイスがどのような出目の内訳でその合計に達したかを、もはや記憶しておく必要がない**」という点である。

たとえば、$(X, Y) = (1, 6)$ と $(X, Y) = (3, 4)$ は異なる出目だが、どちらも同じ $S_2 = 7$ という合計値をもたらす。3個目のダイスを加えた後の分布を計算する際、それが $1+6$ で作られたのか $3+4$ で作られたのかは未来の結果に一切影響しない。必要な情報は、「現在の合計が7である確率」という要約された情報だけである。

この「過去の細かい経過を、未来の計算に必要な情報だけに圧縮してまとめる」という考え方により、計算量を劇的に削減できる。4D10なら $p_{S_4} = p_{S_3} * p_U$、一般の $n$D10なら $p_{S_n} = p_{S_{n-1}} * p_U$ と、1個ずつ順番に畳み込みを繰り返せばよい。

## 2.4 途中結果を再利用して計算する（動的計画法）

この逐次的な畳み込みを、アルゴリズムとして定式化しよう。$n$D10の合計を $S_n$、$n$ 個目のD10の出目を $U_n$ とする。$U_n$ は公平なD10であるため $p_{U_n}(r) = 1/10$（$r=1,\ldots,10$）である。したがって、次の漸化式が成り立つ。

$$
\boxed{
p_{S_n}(s) = \frac{1}{10} \sum_{r=1}^{10} p_{S_{n-1}}(s - r)
}
$$

この式は、「直前の $(n-1)$D10の分布」さえ手元にあれば、わずか10項の足し算で $n$D10の確率を計算できることを示している。

0個のダイスの合計 $S_0$（確率1で値0をとる初期状態）からスタートし、ダイスを1個ずつ足していくアルゴリズムは、擬似コードで次のように表現できる。

```text
distribution ← {0: 1.0}

repeat n times:
    next ← zero-filled probability table

    for each score s in distribution:
        for face ← 1 to 10:
            next[s + face] ← next[s + face] + distribution[s] / 10

    distribution ← next

return distribution
```

このように、小さな問題の計算結果を配列等に記録（メモ化）しておき、それを利用してより大きな問題を順番に解いていく手法を**動的計画法**（dynamic programming; DP）と呼ぶ。

### 計算量の劇的な改善

愚直な全探索では $10^n$ 回の試行が必要だったのに対し、DPではどうだろうか。

$n$ 個のD10を振ったときの合計値の範囲は $n \sim 10n$ の $9n+1$ 通りしかない。$k$ 個目のダイスを追加する際、状態数は高々 $9k+1$ 個であり、それぞれに対して10通りの出目を配分する。したがって、全体の総計算量はダイス数 $n$ の2乗に比例する $O(n^2)$ で済む。

| ダイス数 $n$ | 愚直な全列挙 ($10^n$) | 動的計画法 ($O(n^2)$) |
| :---: | :---: | :---: |
| 2 | 100 通り | 約 20 ステップ |
| 5 | 100,000 通り | 約 120 ステップ |
| 10 | 100億 通り | 約 500 ステップ |
| 50 | $10^{50}$ 通り（計算不可能） | 約 12,000 ステップ（一瞬） |

指数爆発していた計算が、実用上瞬時に終わる多項式時間へと劇的に改善された。

この効率化を支えているのは、「未来に必要な情報だけを**状態**（この場合は現在の合計値）として定義し、同じ状態に至る異なる履歴をすべて束ねる」という抽象化の力である。この思考法は、第11章の《屍人》の解析や、第IV部の高速アルゴリズムでも中核的な役割を果たす。

## 2.5 この章で使った道具

### 畳み込み（独立な和のPMF）
$$
p_{X+Y}(s) = \sum_x p_X(x) p_Y(s - x)
$$

### $n$D10の動的計画法（DP）漸化式
$$
p_{S_n}(s) = \frac{1}{10} \sum_{r=1}^{10} p_{S_{n-1}}(s - r)
$$

## 第I部のまとめ

第1章と第2章を通して、本書で用いる確率計算の最も基礎的な土台が整った。

1. ダイスの出目を**確率変数**として捉え、各値の確率を**確率質量関数（PMF）**で、境界以下の確率を**累積分布関数（CDF）**で記述する。
2. 独立なダイス同士の足し算は**畳み込み**によって計算でき、**動的計画法（DP）**によって状態をまとめながら逐次的に解くことができる。

しかし、ダブルクロスの判定は単なるダイスの足し算ではない。一定以上の出目が出たダイスはクリティカルし、さらなるダイスを追加して無限に伸びていく。

続く**第II部**では、このクリティカル処理を数学的に定式化し、ダブルクロスの戦闘サイクルの完全な確率解析へと踏み出す。
