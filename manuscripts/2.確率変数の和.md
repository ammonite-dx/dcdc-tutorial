# 第2章　確率変数の和

前章では、一つの確率変数について、その確率分布を確率質量関数や累積分布関数で表す方法を見た。しかし、実際のゲームでは複数のランダムな値を組み合わせて使うことが多い。たとえば2D10の合計値を求めるには、二つのダイスの出目を足す必要がある。

本章では、二つの独立な確率変数を足したとき、その和の確率分布をどのように求めるかを考える。この計算を追う過程で、**畳み込み**と**動的計画法**という、基本的だが強力でエレガントな道具を導入する。以降のダメージ計算や特殊なダイス処理でも、この二つの考え方は繰り返し登場することになる。

## 2.1 2D10の合計

二つの公平なD10を振る場合を考えよう。それぞれの出目を $X$、$Y$ とし、その合計を $S=X+Y$ とする。このとき、$S$ が7になるのは、$(X,Y)=(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)$ のいずれかの場合である。どの組み合わせも確率は $1/10\times1/10=1/100$ なので、

$$
P(S=7)
=
6\times\frac{1}{100}
=
\frac{6}{100}
$$

となる。ここで、二つのダイスが互いに影響せず、それぞれ独立に出目を決めることを利用した。たとえば $P(X=2,\ Y=5)=P(X=2)P(Y=5)$ である。このように、一方の結果がもう一方の確率に影響しないとき、二つの確率変数は**独立** (independent) であるという。

同様に計算を進めていくと、2D10の分布は次のようになる。

|   合計 $s$ | $(X,Y)$ の候補                                                              | $P(S=s)$ |
| -------: | :----------------------------------------------------------------------- | -------: |
|        2 | $(1,1)$                                                                  |  $1/100$ |
|        3 | $(1,2), (2,1)$                                                           |  $2/100$ |
|        4 | $(1,3), (2,2), (3,1)$                                                    |  $3/100$ |
| $\vdots$ |                                                                          |          |
|       10 | $(1,9), (2,8), (3,7), (4,6), (5,5), (6,4), (7,3), (8,2), (9,1)$          |  $9/100$ |
|       11 | $(1,10), (2,9), (3,8), (4,7), (5,6), (6,5), (7,4), (8,3), (9,2), (10,1)$ | $10/100$ |
|       12 | $(2,10), (3,9), (4,8), (5,7), (6,6), (7,5), (8,4), (9,3), (10,2)$        |  $9/100$ |
| $\vdots$ |                                                                          |          |
|       19 | $(9,10), (10,9)$                                                         |  $2/100$ |
|       20 | $(10,10)$                                                                |  $1/100$ |

1D10はどの出目も同じ確率だったが、2D10の合計は中央付近ほど出やすい。この違いは、値そのものではなく、その値を作る組み合わせの数によって生じている。

## 2.2 畳み込み

今の計算を一般化してみよう。$S=X+Y$ がある値 $s$ になるためには、$X=x$ かつ $Y=s-x$ となればよい。したがって、$X=x$ となる場合をすべて考えて、その確率を足せば、

$$
P(S=s)
=
\sum_x P(X=x,\ Y=s-x)
$$

となる。$X$ と $Y$ が独立なら $P(X=x,\ Y=s-x)=P(X=x)P(Y=s-x)$ なので、

$$
P(S=s)
=
\sum_x P(X=x)P(Y=s-x)
$$

である。確率質量関数を使えば、

$$
\boxed{
p_S(s)
=
\sum_x p_X(x)p_Y(s-x)
}
$$

と書ける。これが、独立な二つの確率変数の和の分布を求める基本式である。

この計算は $p_X$ と $p_Y$ の**畳み込み** (convolution) と呼ばれ、記号「$*$」を使って $p_S=p_X*p_Y$ と書くこともある。名前は少し難しく見えるが、やっていることは2D10の例と変わらない。「合計が $s$ になるすべての組み合わせを探し、それぞれの確率を掛けてから足す」という計算である。

## 2.3 3D10をどう計算するか

同様の手法を使えば、3D10の分布も計算することができる。三つの公平なD10の出目を $X$、$Y$、$Z$ とし、その合計を $S_3=X+Y+Z$ としよう。$S_3$ が7になる確率を求めたければ、その候補となる組をすべて列挙すればよい。具体的には、

$$
\begin{aligned}
(X,Y,Z)={}&(1,1,5),(1,2,4),(1,3,3),(1,4,2),(1,5,1),\\
&(2,1,4),(2,2,3),(2,3,2),(2,4,1),\\
&(3,1,3),(3,2,2),(3,3,1),\\
&(4,1,2),(4,2,1),(5,1,1)
\end{aligned}
$$

の15組である。出目の独立性から、各組が現れる確率は $1/10^3=1/1000$ だから、$P(S_3=7)=15/1000$ と計算できる。より一般に、

$$
\begin{aligned}
P(S_3=s)
&=
\sum_x\sum_y P(X=x,\ Y=y,\ Z=s-x-y)\\
&=
\sum_x\sum_y P(X=x)P(Y=y)P(Z=s-x-y)
\end{aligned}
$$

と書くこともできる。

さて、この方法を使えば確かに3D10の分布は計算可能である。しかし、ここで一つ問題に気が付く。分布全体を求めるためにすべての出目を列挙するなら、2D10では100組だったのに対し、3D10では1000組の組み合わせを調べなければならない。一般に、$n$ 個のD10の出目の組をすべて網羅するには $10^n$ 通りのパターンを調べる必要がある。2D10や3D10ならまだしも、数十個のダイスの出目をすべて列挙するのは、コンピュータを使っても現実的ではない。どうやら、もう少し賢いやり方が必要そうだ。

そこで、3D10の計算を別の見方で考えてみよう。最初の二つのダイスの合計を $S_2=X+Y$ とすると、3D10の合計は $S_3=S_2+Z$ と書ける。ここで、$S_2$ の分布はすでに2D10の分布として求めていることを思い出そう。したがって、三つのダイスの出目を最初からすべて列挙する必要はない。代わりに、「2D10の合計」という一つの確率変数 $S_2$ と、新しい1D10の出目 $Z$ を足せばよい。つまり、
$$
p_{S_3}=p_{S_2}*p_Z
$$
である。

この見方で重要なのは、最初の二つのダイスについて、どのような出目の組み合わせでその合計に到達したかを、もう覚えておく必要がないという点である。たとえば、$(X,Y)=(1,6)$ と $(X,Y)=(3,4)$ は異なる出目の組み合わせだが、どちらも $S_2=7$ になる。3個目のダイスを追加した後の合計を考えるとき、7が $1+6$ で作られたのか、$3+4$ で作られたのかは結果に影響しない。必要なのは、$P(S_2=7)$ という「現在の合計が7である確率」だけである。

このように、過去の細かい経過を、未来の計算に必要な情報だけにまとめることで、扱わなければならない情報を大幅に減らすことができる。この場合、必要な情報は「現在の合計値とその確率」である。同じ考え方で4D10を計算するなら $S_4=S_3+U_4$ として $p_{S_4}=p_{S_3}*p_{U_4}$ を計算すればよい。つまり、1D10を一つずつ追加し、そのたびに一つ前の合計値の分布だけを使えば、任意の個数のD10の分布を求められる。

## 2.4 動的計画法

前節で導入した考え方を、実行可能なアルゴリズムの形に整理しよう。$n$ D10の合計を $S_n$ とし、$n$ 個目のD10の出目を $U_n$ とすれば、$S_n=S_{n-1}+U_n$ である。$U_n$ は1D10なので $p_{U_n}(r)=1/10$ $(r=1,2,\ldots,10)$ であり、畳み込みの式から、

$$
\boxed{
p_{S_n}(s)
=
\frac{1}{10}
\sum_{r=1}^{10}
p_{S_{n-1}}(s-r)
}
$$

となる。この式は、$(n-1)$ D10の分布さえ分かっていれば、$n$ D10の分布を計算できることを示している。

実際の計算では、0個のダイスの合計 $S_0$ から始めればよい。当然 $S_0$ は必ず0だから、

$$
p_{S_0}(s)=
\begin{cases}
1 & s=0\\
0 & \text{それ以外}
\end{cases}
$$

である。ここから1個ずつD10を追加していけば、$S_0\rightarrow S_1\rightarrow S_2\rightarrow\cdots\rightarrow S_n$ の順に分布を作ることができる。この計算手順を擬似コードで表すと、次のようになる。

```text
distribution ← {0: 1}

repeat n times:
    next ← zero-filled probability table

    for each score s in distribution:
        for face ← 1 to 10:
            next[s + face] ← next[s + face] + distribution[s] / 10

    distribution ← next

return distribution
```

このアルゴリズムでは、それまでに出たダイスの出目そのものは保存していない。保存しているのは、「現在の合計が $s$ である確率」だけである。同じ合計 $s$ に到達する出目の組み合わせが何通りあっても、それらは一つの状態にまとめられる。次のダイスを加えた後の分布を求めるには、過去の出目の並びではなく、現在の合計だけ分かれば十分だからである。このように、小さな問題について求めた結果を保存し、それを利用してより大きな問題を順番に解いていく方法を**動的計画法** (dynamic programming; DP) と呼ぶ。特に重要なのは、未来の計算に必要な情報だけを**状態**として残し、同じ状態に到達した異なる経過をまとめて扱うという考え方である。

$n$ D10の場合、その状態とは「現在の合計値」である。$n$ D10のすべての出目の組を網羅するためには $10^n$ 通りの列挙が必要だが、$n$ 個のD10を振った時点で取り得る合計値は $n,n+1,\ldots,10n$ の $9n+1$ 個しかない。もちろん、DP全体の計算量が $9n+1$ 回で済むという意味ではない。$k$ 個のD10を振った時点ではおよそ $9k+1$ 個の状態があり、それぞれについて次のD10の10通りの出目を処理する必要がある。この計算を1D10から $n$ D10まで繰り返すため、全体の仕事量はおおよそ $n^2$ に比例して増える。それでも、すべての出目を列挙する方法では $10^n$ 通りを扱わなければならない。ダイス数とともに指数的に増えていた問題を、はるかに緩やかな増え方へ変えられたわけである。

このような劇的な効率化が可能なのは、多くの異なる経過を「現在の合計値」という同じ状態へまとめられるからである。この「何を状態として残せば、それまでの細かい経過を忘れても次の計算を続けられるか」という考え方は、後でより複雑なダイス処理を計算するときにも重要になる。

## 2.5 この章で使った道具

独立な確率変数 $X$ と $Y$ の和 $S=X+Y$ の確率質量関数は、

$$
p_S(s)
=
\sum_x p_X(x)p_Y(s-x)
$$

で求められる。この計算を**畳み込み**という。

$n$ D10については、

$$
p_{S_n}(s)
=
\frac{1}{10}
\sum_{r=1}^{10}
p_{S_{n-1}}(s-r)
$$

という式を使い、一つ前の分布から次の分布を順番に計算することで、$n$ D10の分布を動的計画法によって求められる。

ここまでで、複数の普通のD10を足し合わせる問題は解けるようになった。しかしダブルクロスの判定では、単に複数のダイスを足すわけではない。一定以上の出目を出したダイスはクリティカルし、さらにダイスを振り続ける。次章ではまず、もっとも単純な場合として、1個のD10がクリティカルを繰り返したときの判定の出目を確率分布として求める。
